# FinCast Prediction Quality: LLM Review Brief

## Objective
Assess whether the financial movement model is learning useful distinctions, whether it is dominated by class priors, how production predictions perform after outcomes settle, and what training/data changes should come next.

## Data and evaluation definitions
- Training examples: 1,068; validation examples: 157.
- train.jsonl and val.jsonl contain labels used during model training and checkpoint selection; they do not contain model predictions.
- Production source: predictions_log.jsonl, latest row retained per ticker/date; settled rows require actual_move_bin.
- Settled production rows analyzed: 58.
- Five classes, ordered by severity: ['strong_down', 'down', 'flat', 'up', 'strong_up'].
- Exact accuracy requires the full five-class label to match. Direction accuracy maps strong_down/down to down, flat to flat, and up/strong_up to up.

## Label balance
- Training mode: flat (27.62% of training labels).
- Validation mode: flat (31.21% of validation labels).
- Training distribution: {'strong_down': 134, 'down': 219, 'flat': 295, 'up': 232, 'strong_up': 188}.
- Validation distribution: {'strong_down': 13, 'down': 22, 'flat': 49, 'up': 42, 'strong_up': 31}.

## Validation interpretation
- Validation is a training-time model-selection signal because eval_loss, early stopping, and best-checkpoint selection use it.
- This notebook does not calculate validation accuracy because no validation model predictions are produced or expected.
- Compare train and validation label distributions for coverage and imbalance; use settled production predictions for actual prediction quality.

## Settled production evidence
- Exact five-class accuracy: 25.86%.
- Direction accuracy: 51.72%.
- Actual-majority baseline: 48.28% (strong_up).
- Lift over actual-majority baseline: -22.41 percentage points.
- Production prediction mode: up at 44.83%.
- Mean class-distance error: 1.26 ordered class steps.
- Within one ordered class step: 68.97%.

## Important interpretation cautions
- Production rows are a time series and may be correlated; do not treat each row as fully independent.
- The current production sample may be small and class balance can change as more days settle.
- A model can have weak exact accuracy but useful directional accuracy, or good accuracy only because of a dominant class.
- Train-versus-validation label agreement does not prove the model learned; it only checks dataset comparability.

## Questions for the reviewing LLM
1. Does the evidence indicate class collapse, label imbalance, magnitude confusion, ticker-specific failure, or data leakage/duplication?
2. Is exact five-class movement prediction an appropriate objective for this sample size and volatility regime?
3. Should labels be rebalanced, volatility-normalized, downsampled, or changed to directional classification first?
4. What data-quality checks should be performed on news relevance, duplicate stories, dates, price alignment, weekend rows, and target construction?
5. What is the smallest rigorous experiment plan to compare the current model against majority, ticker-majority, directional, and simpler statistical baselines?
6. What additional chronological production data should be collected before trusting improvements?
7. Recommend the next three training experiments, each with a hypothesis, exact dataset change, metric, and pass/fail criterion.
